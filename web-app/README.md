# TG Media Downloader - Web Edition Local Quickstart Guide

## 1. Run Web Frontend (Vite + React)

Open a terminal in the `web-app` directory:

```bash
cd web-app
npm install
npm run dev
```

The web app will open automatically at: **`http://localhost:3000`**

---

## 2. Run Node.js Backend Server (Express API)

Open a second terminal in the `web-app/server` directory:

```bash
cd web-app/server
npm install
npm start
```

The backend server will run at: **`http://localhost:5000`**

---

## 3. Demo Admin Login

To view the **Admin Master Control Portal** locally:
- Click **Sign In** in the top navbar.
- Enter email: `admin@tgdownloader.com` (any password).
- Click **Admin Panel** in the navbar to access payment approvals, blog post editor, contact inbox, pricing manager, free fetch limits, and ad controls!
